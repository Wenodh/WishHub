## 2. Milestone Deep Dive

### Version 1.0 — Universal Launch (Target: Day 90)
- **Objective**: Launch a secure, reliable, and highly polished personal wishlist companion.
- **Features**:
  - Secure account creation via Better Auth.
  - Multi-wishlist management with default lists.
  - Light/dark mode support and responsive web dashboard views.
  - Lite browser extension with offline saving support.
  - Core database index optimizations to ensure fast list loading.

### Version 2.0 — Collaborative Curation (Target: Month 6)
- **Objective**: Drive organic growth through sharing and collaborative curation.
- **Features**:
  - Real-time collaborative lists with permission settings (viewers, contributors, editors).
  - One-click wishlist importing from other platforms (Amazon, Pinterest).
  - Public-facing read-only wishlist links with custom metadata.
  - Mobile app parity using the Expo React Native app.

### Version 3.0 — AI Shopping Companion (Target: Month 12)
- **Objective**: Build an AI-driven personalization and shopping engine.
- **Features**:
  - Automated product tagging, categorization, and taxonomy grouping.
  - AI-generated product comparison summaries (pros, cons, alternative suggestions).
  - Visual similarity search using image embeddings.
  - Interactive chat-based shopping assistant.
