# Release Notes — WishHub v1.0.0

## Executive Summary
WishHub v1.0.0 is the first stable release of our universal wishlist platform. This milestone establishes a robust foundation for product extraction, multi-wishlist management, and cross-platform synchronization.

## New Features
- **Multi-Wishlist Support**: Create and manage multiple collections.
- **Production-Ready Extension**: Seamless product extraction with offline support.
- **Smart Duplicate Detection**: Prevent duplicate saves with canonical URL matching.
- **Responsive Dashboard**: Manage your saves from any device.

## Quality & Security
- **Performance**: Dashboard load times and extension startup optimized for speed.
- **Security**: Hardened authentication (Better Auth) and ownership-based authorization.
- **Accessibility**: WCAG 2.2 AA compliant UI primitives.
- **Testing**: 100% pass rate on critical path integration tests.

## Known Limitations
- Price tracking is currently static; automated history tracking coming in v1.1.
- Rate limiting is not enforced at the application level (relying on infrastructure).

## Roadmap
- **v1.1**: Automated Price Tracking & Alerts.
- **v1.2**: Social Sharing & Collaborative Wishlists.
- **v2.0**: Mobile App (Expo) Beta.
