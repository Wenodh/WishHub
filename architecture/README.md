# Architecture

This directory contains the architectural documentation for WishHub.

## Contents

- [/decisions](./decisions): Architecture Decision Records (ADRs)
- [/diagrams](./diagrams): System diagrams (Mermaid format)

## Overview

WishHub is built as a production-grade, scalable platform using a Monorepo approach with Turborepo. It follows Domain-Driven Design (DDD) principles and a Feature-Based Architecture.
